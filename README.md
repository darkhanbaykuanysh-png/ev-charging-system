# EV Charging System

Электр көлік құралдарын (электромобиль, электросамокат, электромопед, электровелосипед) зарядтау станцияларын іздеу, брондау және төлем жасау бірыңғай ақпараттық жүйесі.

## Мақсаты
Көлік иелеріне станцияны жылдам табуға, брондауға, зарядтау барысын бақылауға және онлайн төлем жасауға мүмкіндік беру; операторларға станциялар мен тарифтерді бір жүйеде басқаруға жағдай жасау.

## Пайдаланушылар
- Көлік иесі (клиент)
- Станция операторы
- Әкімші

## Негізгі функциялар
- Тіркеу және авторизация
- Көлік профилін басқару
- Станцияны картадан іздеу және сүзу
- Ұяшықты брондау
- Онлайн төлем және электронды чек
- Зарядтау барысын бақылау
- Станциялар мен тарифтерді басқару (оператор)

## Репозиторий құрылымы
- `docs/` – талаптар, Use Case, UML диаграммалары
- `db/` – дерекқор сценарийі (SQL Server)
